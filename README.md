# Tic Tac Toe 🎮

A simple **Tic Tac Toe game** built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay (O and X)
- Winner detection
- Draw detection
- Restart game functionality
- Simple and clean UI

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Player O starts the game.
2. Players take turns selecting empty cells.
3. Get three symbols in a row, column, or diagonal to win.
4. Click **Restart Game** to play again.
